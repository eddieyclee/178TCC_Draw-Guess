# 你畫我猜（多人網頁版）— 重新設計版

這個版本改用**傳統 `<script>` 標籤 + Firebase Compat SDK**，取代原本的 ES Module 寫法。三個頁面（首頁、遊戲房間、主席監控台）都是**完全自包含**的單一 HTML 檔案，Firebase 設定值直接寫在檔案裡，不再需要額外的 `firebase-config.js`、`firebase-init.js` 或跨檔案 import，大幅減少可能出錯的環節。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 玩家首頁：輸入暱稱、建立或加入房間（Firebase 設定已內嵌在檔案裡） |
| `room.html` | 遊戲畫面：大廳、畫布、猜題（Firebase 設定已內嵌在檔案裡） |
| `admin.html` | 主席總監控台：同時顯示所有房間的即時狀況（Firebase 設定已內嵌在檔案裡） |
| `style.css` | 共用樣式 |

**如果要換成別的 Firebase 專案**：三個 html 檔案裡都各自有一段 `firebaseConfig = {...}`，改的時候記得**三個檔案都要改到**（因為不再共用同一份設定檔）。

## 部署到 GitHub Pages

跟之前一樣：把整個資料夾 push 到 GitHub repo，Settings → Pages → 選 `main` 分支、`/ (root)` 資料夾即可。

## 本機執行

一樣需要用本地伺服器（不能用 `file://` 直接開），例如：
```bash
npx serve
```
然後開 `localhost:3000`。

## 遊戲流程

1. 每組玩家開啟首頁，一人「建立房間」拿到房號，其他組員輸入房號或點邀請連結加入。
2. 任何人都能按「開始遊戲」（不限定房主，避免某人分頁關掉後整個房間卡住）。
3. 輪到的人自己輸入題目、開始畫，其他人猜答案。
4. 出題者可按「公布答案，結束本題」，或答對人數達全員時系統自動進入結算畫面。
5. 結算畫面公布正確答案、答對人數，分數會累積不會重置。
6. 任何人或主席（`admin.html`）都能按「下一題」繼續。
7. 主席可在 `admin.html` 對任一房間按「開始遊戲」「下一題」「結束遊戲」「刪除此房間」。

## 這個版本跟舊版的差異

- **不再用 ES Module（`import`/`export`）**，改用最傳統的全域 `<script>` 標籤，Firebase 透過 `firebase-app-compat.js` / `firebase-database-compat.js` 這兩支「相容版」SDK 載入，用法是 `firebase.database().ref(...)` 這種傳統風格。這樣可以避開瀏覽器對 ES Module 快取、跨檔案載入失敗時難以除錯的問題。
- 三個頁面完全獨立，不互相 import，減少「其中一個檔案沒抓到，導致全部壞掉」的風險。
- 房主權限放寬：開始遊戲、下一題、重玩，房間內任何人都能操作，不會因為房主的瀏覽器分頁遺失而卡死整個房間。
