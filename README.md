# 你畫我猜

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 玩家首頁：輸入暱稱、建立或加入房間（Firebase 設定已內嵌在檔案裡） |
| `room.html` | 遊戲畫面：大廳、畫布、猜題（Firebase 設定已內嵌在檔案裡） |
| `admin.html` | 主席總監控台：同時顯示所有房間的即時狀況（Firebase 設定已內嵌在檔案裡） |
| `style.css` | 共用樣式 |

**如果要換成別的 Firebase 專案**：三個 html 檔案裡都各自有一段 `firebaseConfig = {...}`，改的時候記得**三個檔案都要改到**（因為不再共用同一份設定檔）。

## 遊戲流程

1. 每組玩家開啟首頁，一人「建立房間」拿到房號，其他組員輸入房號或點邀請連結加入。
2. 任何人都能按「開始遊戲」（不限定房主，避免某人分頁關掉後整個房間卡住）。
3. 輪到的人自己輸入題目、開始畫，其他人猜答案。
4. 出題者可按「公布答案，結束本題」，或答對人數達全員時系統自動進入結算畫面。
5. 結算畫面公布正確答案、答對人數，分數會累積不會重置。
6. 任何人或主席（`admin.html`）都能按「下一題」繼續。
7. 主持人可在 `admin.html` 對任一房間按「開始遊戲」「下一題」「結束遊戲」「刪除此房間」。
